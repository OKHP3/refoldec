# Raw synthetic capture

Someone needs a repeatable way to handle an access request. The requester
sends the request. Someone reviews whether it is complete. If it is complete,
someone approves it and records the decision. If it is incomplete, it goes
back for correction and gets submitted again. If nobody can tell whether it is
complete, stop and ask for escalation instead of guessing.

This deliberately generic capture contains no real organization, policy,
person, system, or confidential data. It is the source material folded into
the Documentation representation for the proof.
